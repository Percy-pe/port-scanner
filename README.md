# 简易多线程 TCP 端口扫描器 (Port Scanner)

这是一个用 Python 编写的轻量级 TCP 端口扫描工具。作为个人网络安全学习的第一个实战项目，旨在理解 TCP 协议连接原理与多线程并发编程。

## ✨ 功能特性
- **多线程并发**：使用 `ThreadPoolExecutor` 线程池，扫描速度极快，防止系统资源耗尽。
- **异常处理**：内置 `try...except` 机制，遇到网络波动或系统限制时不会导致程序崩溃。
- **超时控制**：精准的 `settimeout` 设置，防止在关闭的端口上浪费时间。

## 🛠️ 环境要求
- Python 3.8 及以上版本（无需安装额外第三方库）

## 🚀 使用方法
1. 克隆项目或下载 `scanner.py` 文件。
2. 在终端中运行：
   ```bash
   python scanner.py
3. 根据提示输入目标 IP 和端口范围（例如 1-1000）。
